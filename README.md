## 🚀 Featured Project

**[API-SHOHAG](https://apishohag.netlify.app/)** is a VS Code extension for building and testing HTTP, WebSocket and gRPC requests. Collections are stored as plain JSON so teams can share them through Git. It comes with a sandboxed Node.js scripting engine, a CLI that produces JUnit and HTML reports for CI/CD, and a built-in MCP server so AI tools like Claude and Cursor can discover and run your requests. It also imports from Postman, HAR and OpenAPI.
